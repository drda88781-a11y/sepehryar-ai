# موتور هوش مصنوعی سپهریار (Sepehryar AI Engine)
> **نسخه:** 0.1.0 | **بسته پایتون:** `sepehryar_ai` | **سیستم‌عامل هدف:** Windows (100% Offline)

موتور عملیاتی هوش مصنوعی محلی برای نرم‌افزار حسابداری سپهریار، با هدف تحلیل ساختار پایگاه داده، دستیاری فنی، عیب‌یابی سرور، پرس‌وجوی ایمن (Read-Only) به زبان فارسی و وب‌سرویس REST محلی بدون هرگونه وابستگی به اینترنت.

---

## ۱. ویژگی‌های کلیدی سامانه
* **۱۰۰٪ آفلاین و محلی (Offline Guard):** مسدودسازی سخت‌گیرانه هرگونه تبادل داده با اینترنت و ممانعت کامل از خروج اطلاعات مالی مشتری.
* **اسکنر عمیق پایگاه داده (Deep Database Scanner):** استخراج فوق سریع جداول، ستون‌ها، کلیدهای اصلی/خارجی (PK/FK)، ایندکس‌ها، تریگرها، ویوها و پروسیجرها بدون قفل کردن جداول عملیاتی.
* **دیکشنری تخصصی سپهریار:** شناسایی و برچسب‌گذاری معنایی فارسی جداول اصلی (`TblKala`, `TblPerson`, `TR`, `TblSanad`, `TblAnbar` و ...).
* **اجرای کوئری فوق امن (Safe SQL Engine):** مسدودسازی خودکار و غیرقابل مذاکره کلیه دستورات مخرب (`INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER`, `TRUNCATE`) و اعتبارسنجی مستقل از مدل هوش مصنوعی.
* **پایگاه دانش آفلاین (Knowledge Base & Search):** موتور جستجوی محلی فارسی روی مستندات کدینگ سرفصل‌ها، استانداردهای مهاجرت از هلو/محک/باران، ساختار گزارش‌ساز و راهنماهای رفع مغایرت.
* **خروجی داده آفلاین (Data Exporter):** خروجی مستقیم به فایل‌های CSV (با انکودینگ UTF-8 BOM مخصوص مایکروسافت اکسل)، JSON و جداول Markdown.
* **وب‌سرویس REST محلی (FastAPI Server):** ارائه API محلی مقید به `127.0.0.1:8765` با احراز هویت توکن جهت اتصال نرم‌افزار حسابداری و سایر ابزارها.
* **ردیابی و مانیتورینگ امنیتی (Audit Trail):** ثبت لاگ عملیات همراه با هش کوئری، کاربر، پایگاه داده و مدت‌زمان اجرا با رمزنگاری DPAPI.
* **رابط کاربری مدرن سازمانی (PySide6 RTL):** رابط کاربری فارسی و کاملاً راست‌به‌چپ با پوسته‌ی دارک.

---

## ۲. پیش‌نیازها
* سیستم‌عامل Windows 10 / 11 یا Windows Server 2016+
* Python 3.11+ (تست و اعتبارسنجی شده روی Python 3.14)
* Microsoft ODBC Driver for SQL Server (Driver 17 یا 18 یا Native Client)
* سرویس محلی یا شبکه‌ای Microsoft SQL Server 2012 تا 2022

---

## ۳. نحوه راه‌اندازی و اجرا

### الف) نصب کتابخانه‌ها
```powershell
py -m pip install -r requirements.txt
```

### ب) اجرای نرم‌افزار گرافیکی (PySide6 GUI)
```powershell
py run.py
```

### ج) اجرای وب‌سرویس محلی (REST API Server)
```powershell
py run.py --server --port 8765
```
مستندات تعاملی Swagger بر روی `http://127.0.0.1:8765/docs` در دسترس است.

### د) اجرای دستورات سریع از طریق ترمینال (CLI)
* **پرسش مستقیم از عامل هوش مصنوعی:**
  ```powershell
  py run.py --ask "لیست کالاها"
  py run.py --ask "کدینگ حسابداری بانک‌ها چگونه است؟"
  ```
* **تست اتصال به SQL Server:**
  ```powershell
  py run.py --test-conn
  ```
* **اسکن ساختار پایگاه داده:**
  ```powershell
  py run.py --scan
  ```
* **عیب‌یابی سرویس‌ها و منابع سرور:**
  ```powershell
  py run.py --diagnose
  ```
* **بارگذاری دیتابیس دمو آفلاین:**
  ```powershell
  py run.py --demo
  ```

## ۵. ساختار پروژه
```
d:/ai app/
├── app/
│   ├── config/          # تنظیمات Pydantic و ثوابت سامانه
│   ├── core/            # ماژول‌های لاگر، امنیت DPAPI، Audit و Offline Guard
│   ├── database/        # مدیریت ارتباط pyodbc، اسکنر عمیق و Safe SQL
│   ├── knowledge/       # لودر، ایندکسر و موتور جستجوی پایگاه دانش
│   ├── llm/             # ارائه‌دهندگان مدل زبانی محلی (Llama-cpp, Ollama, LocalEngine)
│   ├── agent/           # چرخه شناختی عامل (Planner, Memory, Schemas, Orchestrator)
│   ├── api/             # وب‌سرویس محلی FastAPI و امنیت Loopback
│   ├── storage/         # مخزن داده‌های محلی SQLite (app.db)
│   ├── tools/           # ابزارهای دیتابیس، استخراج و جستجو با قراردادهای Pydantic
│   ├── diagnostics/     # موتور قوانین سلامت سیستم و عیب‌یابی سرور
│   ├── ui/              # رابط کاربری گرافیکی PySide6 (فارسی و RTL)
│   └── main.py          # نقطه ورود اجرای گرافیکی
├── data/                # فایل پایگاه داده محلی app.db و خروجی‌های exports
├── logs/                # لاگ‌های تفکیک‌شده (app.log, ai.log, audit.log)
├── knowledge_base/      # مستندات و پایگاه دانش محلی سپهریار
├── tests/               # ۵۱ تست خودکار اعتبارسنجی سامانه
├── run.py               # فایل اجرایی ریشه با سوییچ‌های GUI و CLI
└── requirements.txt     # پیش‌نیازهای پروژه
```
